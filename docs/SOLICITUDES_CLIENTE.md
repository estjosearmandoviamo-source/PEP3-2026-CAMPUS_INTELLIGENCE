# Solicitudes y observaciones del cliente

Registro de las mejoras, incorporaciones, correcciones y aclaraciones que el docente
(cliente) pide al equipo **VISION CAMPUS** durante y después de la exposición.

## Cómo se registra

1. En GitHub, ir a **Issues → New issue** y elegir la plantilla **Solicitud / observación del cliente**.
2. El issue debe llevar la etiqueta **`Solicitudes y observaciones del cliente`**.
3. Cada integrante registra las solicitudes que le corresponden con:
   - **Descripción:** qué pidió el docente.
   - **Responsable:** quién del equipo lo cumple (asignado en el issue).
   - **Fecha de cumplimiento:** hasta cuándo se compromete a entregarlo.
4. Al cumplirla, se cierra el issue y se actualiza la tabla de abajo.

## Tipos de solicitud

| Tipo | Ejemplo |
|---|---|
| Mejora | Cambiar o mejorar algo que ya existe |
| Incorporación | Agregar algo nuevo que no estaba |
| Corrección | Arreglar un error |
| Aclaración | Explicar mejor un punto |
