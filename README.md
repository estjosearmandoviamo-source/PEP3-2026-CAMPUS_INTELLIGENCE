# Campus Intelligence

Repositorio central del proyecto **Campus Intelligence**.

## Estructura

- `docs/` — documentación del proyecto, diagramas, presentación, Gantt y pruebas documentadas.
- `src/` — código fuente y componentes de la aplicación.
- `database/` — scripts y diagramas relacionados con la base de datos.
- `tests/` — pruebas del software.
- `resources/` — recursos utilizados por el proyecto.
- `equipo/` — información de los integrantes y sus responsabilidades.

## Equipo

La información actualmente registrada sobre integrantes y responsabilidades se encuentra en [`equipo/`](./equipo/).

## Documentación

El informe del proyecto se incorporará en [`docs/informe/`](./docs/informe/).

## Estado del repositorio

La estructura inicial del repositorio está organizada para incorporar progresivamente la documentación, presentación, cronograma, código fuente, pruebas, recursos y documentación técnica del proyecto.

> Este README se actualizará a medida que se incorporen componentes reales del proyecto.
