# Campus Intelligence

Repositorio central del proyecto **Campus Intelligence**.

## Estructura actual

- `documentos/` — documentación del proyecto. El informe actual se encuentra en `documentos/proyecto/`.
- `base de datos/` — archivos relacionados con la base de datos.
- `pruebas/` — pruebas del proyecto.
- `recursos/` — recursos utilizados por el proyecto.
- `equipo/` — información de los integrantes y sus responsabilidades.
- `src/` — código fuente y componentes de la aplicación.

## Equipo

La información actualmente registrada sobre los integrantes y sus responsabilidades se encuentra en `equipo/`.

## Documentación

El informe actual del proyecto se encuentra en `documentos/proyecto/`.

## Estado del repositorio

El repositorio está organizado para incorporar progresivamente la documentación, código fuente, base de datos, pruebas y recursos del proyecto.
